# 트로이: 최후의 팔랑크스 V15

한 명의 영웅으로 트로이 전장을 돌파하는 PC 브라우저용 뱀서라이크 핵앤슬래시입니다. 자동 공격으로 적 무리를 상대하면서, 정면 패링으로 공격권을 되찾거나 구르기로 위험 지대를 벗어나는 능동 방어가 전투의 중심입니다.

## 실행

Windows에서는 `start-game.bat`을 실행합니다. 브라우저가 자동으로 열리지 않으면 표시되는 `http://127.0.0.1:4173` 주소로 접속하십시오.

Node.js 환경에서는 다음 명령을 사용할 수 있습니다.

```powershell
npm install
npm start
```

첫 온라인 실행 뒤에는 서비스 워커가 게임 셸과 자산을 캐시합니다. 이후 같은 브라우저에서 오프라인으로 다시 실행할 수 있습니다.

## V15 전투

- 한 런에는 선택한 영웅 한 명만 플레이어 개체와 피격 대상으로 존재합니다. 영웅은 테라몬, 아킬레온, 칼카스 중에서 고릅니다.
- 미르미돈 조우는 화면을 따라오는 아군을 만들지 않습니다. 일정 시간 동안 지원 사격이 발생하며 지속시간과 피해량을 기록합니다.
- 패링은 공격 태그, 공격 방향, 패링 활성 구간을 함께 확인합니다. 정면의 `parryable` 공격은 반격하고 `reflectable` 투사체는 되돌리지만, 후방 공격과 `dodgeOnly`, `unavoidable` 공격은 막지 못합니다.
- 구르기는 입력 방향으로 영웅을 이동시키며 활성 구간 동안 `unavoidable`을 제외한 피해를 피합니다. 패링 중 구르기처럼 방어 행동이 겹치는 입력은 거부됩니다.
- 패링과 구르기는 준비·활성·성공·회복 단계가 서로 다른 애니메이션으로 보입니다. 실제 판정 시간은 애니메이션 재생 속도와 분리돼 있습니다.
- HUD는 패링과 구르기의 현재 단계와 재사용 상태를 별도 칸에 표시합니다.
- 패링과 구르기에는 각각 결과를 바꾸는 강화가 세 종류씩 있습니다. 패링은 유효 시간·반격 피해·회복을, 구르기는 이동 거리·회복·종료 직후 보호를 강화합니다.

## 원정과 성장

- 헥토르를 쓰러뜨리면 승리 보상을 한 번 정산하고 결과 화면을 엽니다.
- 결과 화면의 `무한 전장 계속`은 현재 영웅, 체력, 레벨, 무기와 처치 기록을 유지한 채 전투를 재개합니다. 승리 보상은 다시 지급하지 않습니다.
- `다시 출전`은 새 원정을 시작하고, `평의회로`는 전투를 끝내고 메뉴로 돌아갑니다.
- 전장에서 얻은 드라크마는 보급상점에서 최대 체력, 공격력, 이동 속도 강화에 씁니다. 상점은 가격이 다른 세 선택지와 취소를 제공합니다. 잔액이 부족하거나 같은 구매 요청이 반복되면 비용과 효과를 적용하지 않습니다.
- 월계관은 원정 밖의 영구 성장에 사용합니다. 기존 저장의 영웅, 월계관, 영구 강화와 업적은 V15 형식으로 이전됩니다.

## 오늘의 전장과 시간

일반 출전은 시작할 때마다 새로운 난수 시드를 만들어 같은 설정을 반복해도 다른 전개를 만듭니다. 오늘의 전장은 UTC 날짜, 영웅, 난이도, 정렬한 저주 목록으로 결정적 시드를 만듭니다. 적 생성, 강화 선택, 치명타, 보상과 AI 사건은 `gameRng`를 사용하고, 파티클과 장식 효과는 별도의 `visualRng`를 사용합니다. 오늘의 전장은 같은 날짜와 설정에서 화질이 달라도 같은 게임 사건 순서를 재현합니다.

오늘의 전장에는 다음 규칙 중 하나가 적용됩니다.

- 붉은 달: 적 최대 체력 1.15배
- 폭풍의 날: 적대 투사체 속도 1.20배
- 황금 징조: 정예 출현 가중치 1.50배

시간은 용도에 따라 나눠 기록합니다.

- `missionTime`: 보스가 살아 있지 않은 일반 원정 진행 시간
- `combatTime`: 일반전, 보스전, 무한 전장을 모두 포함한 실제 전투 시간
- `bossCombatTime`: 보스가 살아 있는 동안의 교전 시간

메뉴, 강화 선택, 튜토리얼, 일시정지 중에는 세 시간이 증가하지 않습니다. 오늘의 전장 점수에서 시간 항목은 `combatTime`의 내림 정수를 사용합니다.

## PC 조작

- 이동: `WASD` 또는 방향키 / 게임패드 왼쪽 스틱
- 조준 보정: 마우스 방향 / 게임패드 오른쪽 스틱
- 구르기: `Space` / 게임패드 A
- 패링: `Shift` 또는 마우스 오른쪽 버튼 / 게임패드 B
- 궁극기: `Q` / 게임패드 X
- 강화 선택: 숫자 `1`–`3` 또는 카드 클릭
- 일시정지: `Esc`

모바일 가상 스틱과 터치 전투 버튼은 제공하지 않습니다.

## 시각 자산

V15은 투명 배경과 정수 셀 격자를 사용하는 세 아틀라스를 불러옵니다.

- `assets/animations/troy-defense-atlas-v15.png`: 세 영웅의 패링·구르기 단계
- `assets/sprites/trojan-forces-atlas-v15.png`: 트로이 일반·정예·보스 병종
- `assets/obstacles/greek-obstacles-atlas-v15.png`: 기둥·방책·바위·화로

각 PNG 옆의 JSON manifest가 셀 크기, 프레임, 렌더 키와 교체·유지 매핑을 정의합니다. 로더 오류와 누락된 렌더 키는 `window.__TROY_V15__.audit()`에서 확인할 수 있습니다.

`artifacts/visual/v15-full-roster-contact-sheet.png`는 적 29종과 장애물 4종을 한 장에서 비교합니다. 이 가운데 atlas 밖에서 불러오는 V15 적·보스 19종은 비어 있지 않은 이미지와 최소 2px의 투명 여백을 검사합니다. 세부 측정값은 `artifacts/visual/v15-asset-audit.json`에 기록돼 있습니다.

## 검증

```powershell
npm test
npm run e2e:defense
npm run e2e:run
npm run balance
```

- `npm test`: 방어 규칙 14개, 자산 계약 5개, 런 규칙 15개 등 Node 테스트 34/34와 커버리지 기준을 실행합니다.
- `npm run e2e:defense`: 세 영웅의 단독 렌더, 패링·구르기, 지원 사격, 개체 상한과 오프라인 재부팅을 Chromium에서 확인합니다. DEFENSE 인수 기준은 16/16 PASS입니다.
- `npm run e2e:run`: 헥토르 승리, 무한 전장, 보급 구매, 일반·일일 시드, 저장 이전과 PC 화면 배치를 Chromium에서 확인합니다. RUN 인수 기준은 13/13 PASS입니다.
- `npm run balance`: 고정 시드 기반 밸런스 시뮬레이션을 실행합니다.

전체 브라우저 회귀는 `npx playwright test --workers=1`로 실행하며 현재 31/31 시나리오가 통과합니다. 필요하면 `npm run check`로 JavaScript 구문과 V15 manifest·서비스 워커 구조를 먼저 검사할 수 있습니다.
